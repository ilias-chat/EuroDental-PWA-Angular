Installez l'application

Pour utiliser EuroDental, installez l'application sur votre appareil. Elle s'ouvrira ensuite dans sa propre fenêtre, comme une application native.

Installer l'application

Si le bouton ne fonctionne pas, suivez les instructions ci-dessous.

Installation manuelle sur Android

  1. Ouvrez cette page avec Chrome.
  2. Ouvrez le menu ⋮ du navigateur.
  3. Choisissez Installer l'application ou Ajouter à l'écran d'accueil.
  4. Confirmez l'installation.

Installation manuelle sur iPhone

  1. Ouvrez cette page avec Safari.
  2. Ouvrez le menu Partager.
  3. Choisissez Sur l'écran d'accueil.
  4. Confirmez avec Ajouter.

L'installation sur iPhone fonctionne depuis Safari.
